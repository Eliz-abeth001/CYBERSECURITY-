Key Concepts I Learned

TCP vs UDP

TCP focuses on reliable delivery. It establishes a connection and can retransmit data when necessary.

UDP focuses on speed and lower overhead. It does not provide the same delivery guarantees as TCP.

Bandwidth vs Throughput

Bandwidth is the maximum capacity of a network connection.

Throughput is the actual amount of data successfully transferred over the network per unit of time.

Throughput normally cannot exceed the available bandwidth.

DHCP vs DNS

DHCP automatically provides network configuration such as an IP address, subnet mask, and default gateway.

DNS translates domain names such as google.com into IP addresses.

Switch vs Router

A switch connects devices within a local network.

A router connects different networks and can provide a path between a local network and the internet.

MAC Address vs IP Address

A MAC address identifies a network interface at the data-link layer.

An IP address is used for logical addressing and communication across networks.
